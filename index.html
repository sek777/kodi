📦 My Kodi Files

💡 How to Install via Kodi

  1. Go to Settings ➔ File Manager ➔ Add source
  2. Enter the URL: https://sek777.github.io/kodi/
  3. Go back to Add-ons ➔ Select Install from zip file ➔ Choose the added source
  • 📦
    script.thai.font.changer-2.5.0.zip

    Adds Thai font support to Kodi. Once installed, the system will switch to the Arial font.

    Note: If the font changes unexpectedly in the future, please manually set it back to Arial in Kodi settings.
